# Rosacea Metabolite-Sensor Axes — Reproducible Analysis

Analysis code for: **"Microbial Metabolite-Sensor Communication Axes in Rosacea Prioritized by Multi-Omics Integration"** (revision for *Frontiers in Immunology*).

All results in the manuscript were generated by the scripts in this repository from public data. Every intermediate dataset referenced by the supplementary tables is in `output/`.

## Layout

```
scripts/
  m2_microbiome/   16S rRNA re-analysis (DADA2 + IdTaxa), genus-metabolite-sensor evidence table
  m3_mebocost/     receiver-side scoring (not run: controlled-access scRNA-seq unavailable)
  m4_bulk/         GSE65914: RMA/limma DEG, nested CV classifier, CIBERSORT, GSEA, figures
  m5_drugs/        DGIdb query results, Vina docking
  figures/         Figure 1 (flow chart), Figure 3 (candidate metabolites)
data/              manifests + database extracts (raw files not committed)
output/            all intermediate result tables used by the manuscript
logs/              run logs
```

## Data sources

- PRJNA1189573 (SRA) — Joura et al. 2024 skin 16S rRNA (31 samples)
- GSE65914 (GEO) — Buhl et al. 2015 bulk microarray (58 arrays)
- Published metabolomics tables: Li et al. 2025 (BMC Microbiol, Additional files), Zhang et al. 2025 (Front Mol Biosci)
- MiMeDB v2.0 flat files (mimedb.org, downloaded 2026-08-24; not redistributed here)
- MEBOCOST human met-sensor DB (kaifuchenlab/MEBOCOST, Oct 2025 release)
- LM22 signature (Newman et al. 2015, Supplementary Table 1)
- SILVA v138.1 (via QIIME2 mirror) — converted locally to a 7-rank, pure-ACGT, 400-bp IdTaxa training set (400,300 sequences; build script in data/silva/)

## Note on 16S re-analysis (updated 2026-08-26)

The deposited skin samples of PRJNA1189573 were re-processed with DADA2 and classified
with an IdTaxa classifier trained on a V3-V4 primer-extracted SILVA v138.1 reference
(301,898 sequences; `data/silva/silva_train_v34.fa.gz`, built from `silva_train_7rank.fa.gz`
by 341F/806R primer matching). The resulting composition was dominated by Escherichia
(the five most abundant ASVs match Escherichia coli/fergusonii at 100% identity in BLAST
against NCBI nt), which does not reproduce the published genus composition of the same
cohort (Joura et al. 2024: Cutibacterium-dominant). This discrepancy is reported in the
manuscript as a reproducibility caveat; genus-level differential results in the manuscript
are taken from the published study (Table 2). The earlier V1-V3-region training set
(`silva_train_acgt.fa.gz`) is superseded by the V3-V4 set.
